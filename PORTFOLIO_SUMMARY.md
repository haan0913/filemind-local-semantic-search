# Portfolio Summary: FileMind

FileMind is a local-first semantic file search engine for private Windows workspaces. It indexes local documents/code, extracts text, chunks content, embeds with BGE-M3, stores vectors in Qdrant, and supports hybrid search with keyword/sparse signals plus reranking.

This public repo is a clean-history code cut. The original private development repo contained old experimental smoke-test history and is not being made public.
